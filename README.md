# harley-salinas
John Harley Salinas' artist portfolio

## Project Overview
This project is a comprehensive platform designed to showcase the artistic works of John Harley Salinas. It provides an interactive and visually appealing way to explore his portfolio, learn about his artistic journey, and stay updated with his latest creations.

## Features
- **Dynamic Gallery**: A visually stunning gallery that dynamically displays John Harley Salinas' artworks, categorized by medium and style.
- **Artist Biography**: Detailed information about John Harley Salinas, his background, and his artistic influences.
- **Responsive Design**: A fully responsive design that ensures an optimal viewing experience on all devices, from desktops to mobile phones.

## Technologies Used
- **Frontend**: HTML, CSS, JavaScript
